## 1. 背景、目标与范围

查新报告指出：时间组合一致性已有同类工作（4DGS-JEPA 的 L_comp 等），审稿人最先会问“一致性是不是只等于多训几步滚动”。现有条件里只有 AC 基线用官方两步自回归，PO-JEPA 没有“有真值的多步滚动训练”对照。Jerry 2026-11-12 定：只加 PO-JEPA 滚动版，时间一致性项换成有真值的两段滚动损失 ‖Φ(σ)Φ(τ)z − z_target(τ+σ)‖，同一 (τ,σ) 采样、同一 λ 标定方法，仿真数据集 12 个场景各一条，DROID 不做，Transformer 不加。

不做：改其他 11 个仿真条件；DROID；v7 场景补跑（`make_addon_jobs.py`、`summarize_addon.py`）；Overleaf 引用和措辞（另一个线程）。

## 2. 数学定义（08 §6）

τ = σ = T/2，T ∈ {1, 2, 4, 8} 个控制周期（`queries.temporal_split: equal_halves`），训练批里 duration = τ + σ 逐位成立。

- direct = Φ(Z, u1⊕u2, τ+σ)，intermediate = Φ(Z, u1, τ)，composed = Φ(intermediate, u2, σ)（`losses.temporal_predictions`，3 次完整 Φ）
- d(P, Y) = mean_B mean_(N,E) |LN(P) − LN(Y)|（式14，`losses.jepa_distance`：无 affine LN、eps 1e-5、p = 1、Y 停梯度）
- L_JEPA = d(direct, Z_target)，**L_roll = d(composed, Z_target)**，Z_target = `batch.raw_target`（τ+σ 时刻真实帧，两项同源）
- L = L_JEPA + w(s)·(λ_r·L_roll + λ_s·L_space)；L_space、λ_s、w(s) 和 po_jepa_full 相同
- λ_r = ρ·median|∇L_JEPA| / median|∇L_roll|，ρ = 1，在 v7 calibrate 同样的 300 步 JEPA 预训练之后的 32 批上量

**待 Jerry 确认的一处**（线程里的决策卡）：距离用 JEPA 距离、不除 (τσ)²（Claude 推荐）。另一个读法是照搬时间项 mean((composed − Z_target)/s)² / ((τσ)²+ε)；它让 T = 1 的样本权重是 T = 8 的 4096 倍，而真值误差不随 τσ → 0 消失。Jerry 选另一个读法时只改 `rollout_supervision.py` 一个函数和对应测试。

## 4. 用法

```
python tools/make_v8_jobs.py --stage addon --scenes <12 个场景> --conditions po_jepa_rollout_sup > jobs-v8-rollout.txt
#  AC 补跑标定 12 条（三个要标定的条件一起标）、AC2 检查 1 条、AD 训练+评测 36 条（12 × 3 个种子）、AE 汇总 1 条
```

12 个场景要显式写 `--scenes`（默认只有 7 个一阶场景）；5 个二阶场景仍要等 S22 探针和 S25b。补跑标定文件格式变了（多一项），之前没有写过这个文件，不影响已有结果。

## 5. 验收单

1. L_roll 用的是 composed、不是 direct 或 intermediate；目标是 `batch.raw_target`、停梯度；梯度经 intermediate 传回两段。
2. 距离和 JEPA 项逐位相同（同一个 `jepa_distance`），不除 (τσ)²、不用 `consistency_metric`。
3. 单步：日志六项、总损失和梯度等于手写 L_JEPA(direct) + λ_r·L_roll + λ_s·L_space；预热系数 0 的第 0 步和 po_jepa_full 的第 0 步逐位相同，第 1 步起不同。
4. 构造：初始权重哈希等于 po_jepa_full，谱是 GraphSpectrum；λ_s 用协议值，λ_r 用补跑标定。
5. 标定：预训练和 v7 calibrate 相同（no_consistency）；量的是 L_roll 的梯度；只标 λ_r；文件里 λ_s 等于协议值，否则读不进来。
6. 检查点标签 `rollout_sup`，和 po_jepa_full 互相读不进来；20 步续训和不中断逐位相同。
7. 仿真数据集任务表：12 个场景只排这个条件时 36 条训练；v7 场景补跑任务表不变。
