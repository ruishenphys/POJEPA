## 2. 共同约定

- **两帧输入**：二阶系统一帧看不到速度。每条轨迹多仿真、多画一帧 t = −1，共 34 帧，下标 f 对应 tick f − 1（与 S22 探针相同）。初值在 t = −1 抽（随机流 0），t = −1 → 0 是零动作的“预跑”一个 tick（与 `delay` 调节项在 t = 0 之前补零的约定一致），之后第 t 个 tick 执行 u[t]。数据集的 33 帧是下标 1…33，与一阶场景对齐；下标 0 只给 pair 编码 t = 0 那一刻的前一帧。
- **动作**：执行动作 [32,2] float64（v6 的二维动作协议；S23b 接 `applied_ticks`）。
- **续算**：`advance(q, u, params, start, ticks)` 从 tick=start 的状态推进；`trajectory()` = 初值 + 预跑 + `advance(0, 32)`，所以从任意 tick 续算与整条轨迹逐位相同（反事实探针、规划用，测试核）。
- **画面**：256×256×3 uint8；世界坐标 y 向上，中心列 = 128 + SCALE·x，中心行 = 128 − SCALE·y。单帧只由位置决定（测试核：同位置、不同速度 → 同一画面），速度由相邻两帧给出。
- **观察调节项**：color、background、pixel_noise、occluders 都适用；sigma、distractors、movers 适用于光点类场景（pendulum、cart_pole、spring_chain）；bouncing_balls 的球是有物理半径的圆盘，不接受 sigma；wave 是场，不接受 sigma、distractors、movers。图层顺序与 `systems.compose` 相同：背景 → 静止干扰光点（流 3）→ 会动的干扰光点（流 8）→ 场景 → 遮挡块（流 7）→ 像素噪声（流 4）。
- **像素噪声**：一次抽 [34,256,256,3]，第 f 帧用第 f 份；只画部分帧时按 tick（−1…32）取同一份（S21b 的规则推广到 34 帧），所以单帧重画与整条轨迹的那一帧逐位相同。
- **随机流**：熵 [1703, 1000+i, 轨迹编号, 流号]，i = 7（pendulum）、8（bouncing_balls）、9（wave）、10（cart_pole）、11（spring_chain），即 S23b 把五个名字按这个顺序追加到 `datasets.SYSTEMS` 末尾（gray_scott 5、push 6 之后）的位置；登记后 `simulation.seed_entropy` 给出同一个熵，已有 7 个场景不受影响。
- **物理参数**：名字 → (默认值, 允许范围)，暂时在本文件的 `PARAMS`，S23b 并入 `variants.PARAMS`（之后本文件改成从那里取，与 `new_systems` 相同）。整数参数（n）只接受 int。

## 3. 五个场景（公式即实现，见各类的 docstring）

**pendulum**（二阶，非线性振荡，状态相关的欠驱动）。θ̈ = −(g/L)·sin θ − γ·θ̇ + K·(u_x cos θ + u_y sin θ)，K = 4 rad/s² 每单位动作。θ = 0 竖直向下，θ 增大时摆锤往右；动作是作用在摆锤上的二维力，只有切向分量起作用。参数 `g_over_l` 9.81 ∈ [4, 16] s⁻²、`damping` 0.2 ∈ [0, 1] s⁻¹。初值 θ ∈ U(−π, π)、θ̇ ∈ U(−3, 3)。RK4，每 tick 50 步。画面同 S22 探针（支点在中心，摆杆 80 像素，摆锤是光点）。状态 (θ, θ̇)。物理和 S22 探针单摆相同（K、g/L、γ 的默认值一样），只是动作从标量力矩换成二维力。

**cart_pole**（二阶，欠驱动）。小车（M = 1）+ 无质量杆末端的点质量（m = mass_ratio·M），θ = 0 竖直向上：
- (M+m)ẍ + m·l·cos θ·θ̈ = F + m·l·θ̇²·sin θ − b·ẋ + F_wall，F = K·u_x（K = 1.5，u_y 不起作用）；
- m·l·cos θ·ẍ + m·l²·θ̈ = m·g·l·sin θ − m·l²·0.1·θ̇（摆的转动阻尼）；
- 轨道缓冲：|x| > 1.6 后 F_wall = −400·(|x| − 1.6)·sgn x − 20·ẋ。
参数 `length` 1 ∈ [0.6, 1.4]、`mass_ratio` 0.3 ∈ [0.1, 1]、`friction` 0.5 ∈ [0, 1]。初值 x ∈ U(−1, 1)、ẋ ∈ U(−0.5, 0.5)、θ ∈ U(−π, π)、θ̇ ∈ U(−2, 2)。RK4，每 tick 100 步。画面每单位 36 像素：轨道、缓冲块、小车矩形、摆杆、摆锤光点。状态 (x, ẋ, θ, θ̇)。

**spring_chain**（二阶，线性，模态频率可解析写出）。n 个单位质量质点，静止位置在 x 轴上等距（两端固定在 x = ±2 的墙上），位移 d_i ∈ R²（两个方向方程相同、互不耦合）：d̈_i = −k·(2d_i − d_{i−1} − d_{i+1}) − γ·ḋ_i + [i = 0]·K·u，K = 1.5。模态 ω_j = 2√k·sin(jπ/(2(n+1)))，有阻尼时 √(ω_j² − γ²/4)、衰减 γ/2；第 0 个质点在每个模态里都有分量，所以动作能激发全部模态。分段常数动作下用 [d, ḋ, 1] 增广系统的矩阵指数精确推进（scipy.linalg.expm），没有时间离散误差。参数 `n` 4 ∈ 2…6、`stiffness` 16 ∈ [9, 25]、`damping` 0.1 ∈ [0, 0.5]。初值 d ∈ U(−0.15, 0.15)²、ḋ ∈ U(−0.5, 0.5)²。画面：墙条、弹簧细线、质点光点（第 0 个调节项颜色）。状态 = 位置 [n,2] + 速度 [n,2]。

**bouncing_balls**（二阶，混合系统：碰撞造成的不光滑动力学）。方盒（墙在 |x|, |y| = 2）里 n 个单位质量、半径 0.2 的球，俯视无重力：dv_i/dt = −β·v_i + [i = 0]·K·u，K = 1.5。碰撞之间按解析解推进；每 tick 32 个子步，子步末尾有重叠就二分 60 次找最早的接触时刻（取接触前一侧），施加冲量（墙 v_n ← −e·v_n；等质量两球沿连心线 Δ = −(1+e)·v_rel,n/2），再推进剩下的时间。接近速度 < 0.05 且动作把它往里顶时按静止接触处理（法向速度置零、位置投影），避免把球顶在墙上时的无穷次碰撞；没有往里顶的加速度时照常反弹。墙是硬约束（投影最后截回）。参数 `n` 3 ∈ 1…5、`restitution` 0.9 ∈ [0.5, 1]、`drag` 0.2 ∈ [0, 1]。初值：位置拒绝抽样（两两间距 ≥ 0.45），速度 ∈ U(−1.5, 1.5)²。画面：方框墙，球是抗锯齿圆盘（半径 9.6 像素，第 0 个调节项颜色）。状态 = 位置 [n,2] + 速度 [n,2]。

**wave**（二阶场，线性）。周期方域 [0,1)²：u_tt = c²∇²u − γ·u_t + load·c²·∇²B(x − p)，dp/dt = 0.4·u（域长/秒）。B 是 σ = 0.03、峰值 1 的周期高斯；源取这个形状是因为静止时的稳态正好是 u = −load·(B − B̄)（压出深 load 的凹陷，与 c 无关），源的空间平均为 0，均匀模不受力。源一动就拖出尾迹，比 c 快时出现马赫锥。时间推进：每个傅里叶模是阻尼振子，每 tick 16 个子步，子步内源取中点位置（相移 e^{−ik·p}，亚像素平移，二阶精度），常数强迫下用精确传播子推进；k = 0 单独处理；每个 tick 从实空间的场重新做 FFT，所以续算逐位相同。格点 N = 128（每格 2 像素），空间是谱方法。参数 `speed` c 0.15 ∈ [0.08, 0.3]、`damping` 0.1 ∈ [0, 0.5]、`load` 0.25 ∈ [0, 0.4]；范围保证所有非零模欠阻尼（γ/2 < 2πc）。c 大时高波数模每帧转过的相位超过 π（每域长超过 2/c 个波长的成分），两帧之间会混叠，这是规划 §1.3 说的“测时间离散”。初值：3 个高斯团（σ ∈ U(0.04, 0.08)、幅值 ±U(0.2, 0.4)）减空间平均，再叠加源在 p0 的稳态凹陷；u_t = 0。画面：像素 = 背景 + u⁺·(调节项颜色 − 背景) + u⁻·(蓝 − 背景)，线性，|u| ≤ 1 时不截断、可从 RGB 解回；源画成品红细圆环。完整状态 [u, u_t, p]（2N² + 2 维）；隐藏状态 514 维（u、u_t 各 16×16 池化 + p）。
