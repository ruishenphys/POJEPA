## 1. 为什么有这一段

2026-11-08 晚，Jerry 决定直接采用导师的写法作为主模型：动作驱动和非线性交互改在 token 空间计算，再投影回模态，

    dC/dt = A(Λ, g) C + Ψᵀ [ B(X_t, a) + F(Ψ C, X_t, a) ]，

A 和式(4)不变。代码在 `src/po_jepa/dynamics.py` 的 `DynamicsConfig.forcing_space`（`"modal"` 默认、逐位等于旧式；`"token"` 新式），v7 协议在 `configs/train/v7.yaml` 末尾设 `model.dynamics.forcing_space: token`。这已经推到线上 v7（提交 `0ac45fe03bf43b96bf861446b8aa2ada4f4a8987`，在 `14d7f66` 之上），机哥用它跑正式运行。

full-model 现在建在 v7 的 `911bc09` 上：仓库根目录是 911bc09 的 v7 树，`po-jepa-full/` 是 911bc09 的拷贝加 S00、S08a、S10a 的改动。本段把两者都换到 0ac45fe 上，并把所有依赖“PO-JEPA 是模态写法、215,778 个参数”的地方改成 token 写法的数，让后面的 S10b、S17、S18a、S18b 在新底座上做。
