## 2. 两个场景（公式即实现，见各类的 docstring）

**gray_scott**（一阶场，非线性）。周期方域 N=128 格（每格 2 像素）：
- ∂U/∂t = D_u∇²U − UV² + F(1−U)；∂V/∂t = D_v∇²V + UV² − (F+k)V + a·G(x−p)(1−V)；dp/dt = 0.4·u（域长/秒，周期回绕，y 向上）。
- D_u=0.16、D_v=0.08（格²/时间单位）；每 tick（0.25 s）推进 20 个时间单位；G 是 σ=2 格的周期高斯。
- 初值（流 0）：U=1、V=0，4 个 10×10 方块 U=0.5、V=0.25，±0.01 均匀噪声；p0 均匀；注入点不动烧入 1000 个时间单位，烧入后是第 0 帧。
- 时间推进：Strang 分裂（扩散半步精确 → 反应 RK4 整步，注入点取步中点 → 扩散半步），dt=0.5。
- 画面：像素 = 背景 + 0.6·V·(调节项颜色 − 背景) + 0.4·(1−U)·(青色 − 背景)，线性不饱和（最大约 221），(U, V) 可从 RGB 解回；注入点画品红细圆环 → U、V、p 都可见。隐藏状态 514 维（U、V 各池化成 16×16，加 p）。谱方法有约 1e−5 的负浓度下冲，不 clamp 物理场。
- 物理参数：`feed` 0.04 ∈ [0.035, 0.05]，`kill` 0.06 ∈ [0.0595, 0.063]，`inject` 0.05 ∈ [0, 0.2]。范围由扫描定：feed {0.03…0.05 步长 0.005} × kill {0.0595, 0.061, 0.062, 0.063} × inject {0, 0.2} × 3 条轨迹，只有 feed=0.03、kill=0.063、inject=0 熄灭（V 空间标准差 ~1e−35），其余组合第 0 帧和第 32 帧 V 空间标准差都 ≥ 0.046，所以 feed 下限取 0.035。k ≤ 0.058 且 F ≥ 0.045 时 V 收敛到均匀态，也排除。

**push**（一阶，刚体接触 + 库仑静摩擦阈值，无惯性）。净外力落入静摩擦阈值内方块就静止；停止推动后接触力约 3 ms 内松弛，方块在第一个 tick 内还滑 <1e−3，之后静止（坡面自滑除外）。状态 (c_x, c_y, b_x, b_y, θ)：
- 推杆：dc/dt = 2·u − f + 墙（推力有限，被顶住会停）。
- 接触：推杆圆盘（半径 0.15）穿透方块（边长 size）深度 δ 时，方块受 f = 150·δ·n，作用点为方块边界上的最近点，产生力矩 τ。
- 坡面：切向力 W·slope·(cos φ, sin φ)，法向力 W·√(1−slope²)。
- 方块：椭圆极限面 ‖w‖ = √(F²+(τ/ρ)²)，ρ = 0.383·size；s = max(0, 1 − μ_s·N/‖w‖)；db/dt = s·F，dθ/dt = s·τ/ρ²。
- RK4，每 tick 256 步。画面：方块浅灰（体坐标 (+0.25·size, 0) 处一个深色标记点，区分朝向），推杆为光点。
- 物理参数：`mu_s` 0.3 ∈ [0, 1]，`slope` 0 ∈ [0, 0.6]，`slope_dir` 0 ∈ [−180, 180] 度，`size` 0.8 ∈ [0.4, 1.2]。
- 动摩擦 `mu_k` 和粘滑需要惯性（二阶），放到二阶场景阶段。

**随机流**：熵 [1703, 1000+i, 轨迹编号, 流号]，i = 5（gray_scott）、6（push），即 S20b 追加到 `datasets.SYSTEMS` 末尾后的位置；登记后 `simulation.seed_entropy` 给出同一个熵，v7 的 5 个场景不受影响。流 0 初值、3 干扰光点、4 像素噪声（与 `systems.compose` 相同）。

**通用调节项**：观察类（color、background、pixel_noise；push 还有 sigma、distractors）在本文件里生效；控制类（gain、axes、segments、zero、noise、delay）在 S20b 由 `commanded_controls`/`applied_ticks` 作用到传入的执行动作上。
