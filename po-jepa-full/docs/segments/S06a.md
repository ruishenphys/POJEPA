## 1. 目标与范围

阶段 4 的主体：任务 `encode/<片名>` 把这片每条准备检查通过的回合的取帧位置（第 0、15、30……帧）用冻结的 V-JEPA 2 ViT-g 编码成 float16 [F, 256, 1408]，写特征文件、每行 SHA 和来源记录；全片完成后写片清单和完成记录；训练读取时用 `FeatureReader` 逐行核 SHA；`--delete-raw` 在清单重读核对通过后删训练片的原始文件。另加 `droid/poses.py`（AC 的状态积分，14 §3 S06 要求在本段核对）。

S06 拆两段（Claude 定）：**S06b** 做测试附加 `encode/test-extra`（05 §4：s5 原始帧率、192/320 原始分辨率，即 v8 规划缺口第 7 项），复用本段的 `preprocess_square`、`fake_encoder`、`encode_frames`、`features.to_storage/row_sha256/write_features`。

不做：测试附加（S06b）；`tools/droid.py --job encode/<片>` 统一入口（S14）；窗口采样、组批、吞吐（S07 及以后）；05 §7 的 GPU 核对（没有 GPU，交给算力方）。v7、第零期、S01–S05 的代码不动。

## 3. 接口和产物

- `features/<片>/<uuid>.npy`：float16 [F, 256, 1408]（`np.save`，先写 `.npy.tmp` 再改名）。
- `features/<片>/<uuid>.json`（`cache._write_json`）：`schema: droid_features_v1`、`uuid`、`shard`、`rows`、`shape`、`dtype`、`file`、`file_sha256`、`row_sha256`（每行 float16 字节）、`frame_index`、`frame_sha256`（抄自准备文件）、`prepared_sha256`、`encoder`（`evidence_role`、`encoder_checkpoint_sha256`、`preprocess_sha256`、`batch_frames`、`upstream_commit`）、`encoder_load_report`、`feature_stats`（`max_abs`、`relative_rounding_error`）、`source`（代码提交、4 个源文件 SHA、python/torch/CUDA/numpy/OpenCV 版本、设备、GPU 型号、驱动）、`seconds`。
- `features/<片>/MANIFEST.<配置名>.json`：`schema: droid_feature_manifest_v1`、片、配置和 SHA、`splits_sha256`、`prepare_complete_sha256`、`encoder`、`episodes`（uuid、特征 JSON SHA、文件 SHA、行数）、`skipped`（uuid、原因）、`counts`。
- `features/<片>/_complete/<配置名>.json`：`schema: droid_encode_complete_v1`、片、配置和 SHA、`manifest_sha256`、`code_commit`。
- 特征总清单 SHA：`features.feature_manifests(data_root, config)` 返回 (片清单, SHA)，SHA = SHA-256(按片名排序连接各片清单 SHA 的十六进制串)。
- `raw/<片>/<uuid>/RAW_DELETED.json`：`schema: droid_raw_deleted_v1`、uuid、片、`deleted_at`、`feature_json_sha256`、`files`。

## 4. 实现上自己定的（规格没写死、可逆）

1. **清单按配置分文件** `MANIFEST.<配置名>.json`（05 原写 `MANIFEST.json`）：试跑和正式运行的 `train-000` 回合列表不同（500 / 1000 条），同 S05 把 STATS 按配置分文件。
2. **编哪些回合**：两种动作源任一通过就编（特征只和画面有关，两种配置共用一份）；都没通过的记为跳过，原因抄自准备文件。
3. **跳过规则**另要求片名、证据角色、上游提交一致（05 §3 列的五项之外）。
4. **假编码器**用 `preprocess_square(·, 256)`（CPU 测试没有上游代码），记自己的预处理 SHA，不冒充 v7 的；真实编码器用 v7 `preprocess_rgb`、记 v7 的 SHA。两者逐位相同由测试保证。
5. **`--delete-raw`**：先 `verify_shard`（特征 JSON SHA、整个 `.npy` 文件 SHA、dtype/形状/行数、每行 SHA）；每条先写 `RAW_DELETED.json` 再删 h5 和 MP4（中断后重跑会删掉剩下的）；准备没通过、没编码的回合不删；完成记录已在时仍做删除那一步（幂等）。
6. **进度日志写 stderr**，stdout 只有结果 JSON。
7. **每次送进编码器的块**按行序连续切 `batch_frames`（32）；每帧前新建 `Generator().manual_seed(0)`（v7 规则，预处理 SHA 里含这条）。
