### 3.5 新文件 `src/po_jepa/generic_consistency.py`（08 §3）

全文如下（85 行，以一个换行结尾）。两个函数体从 `losses.py` 逐行照抄，只改三处：参数注解 `model: POJEPA` 换成 `model: nn.Module`，文档字符串变短，`isinstance(model, POJEPA)` 的两行换成 `_require_predictor(model)`。报错文字、检查顺序、返回字段的顺序全都不变（A8 用脚本核对）。

```python
"""08 §3：不限模型类型的式15/16一致性预测（transformer_consistency 用）。

两个函数逐行照抄 losses.temporal_predictions / losses.spatial_predictions，只把
isinstance(model, POJEPA) 换成 _require_predictor：model 是 nn.Module，forward 恰好接受
4 个位置参数 (raw, controls, duration, grid)，并有正整数 encoder_dim。返回 losses 里原有的
TemporalPredictions / SpatialPredictions，交给 losses 里原有的 temporal_consistency_loss、
spatial_consistency_loss、weighted_total_loss。本模块不定义损失，不改 losses.py。
"""

import inspect

import torch
from torch import Tensor, nn

from .actions import ActionSegments, split_action_segments, concatenate_action_segments
from .geometry import GridSpec, SpatialTransfer, apply_spatial_transfer
from .losses import (SpatialPredictions, TemporalPredictions, _temporal_raw_contract,
                     _temporal_time_contract, input_scale)


def _require_predictor(model) -> None:
    """代替 isinstance(model, POJEPA)：nn.Module、forward(raw, controls, duration, grid)、正整数 encoder_dim。"""
    if not isinstance(model, nn.Module):
        raise TypeError("model must be an nn.Module")
    parameters = list(inspect.signature(model.forward).parameters.values())
    if (len(parameters) != 4
            or any(p.kind not in (inspect.Parameter.POSITIONAL_ONLY, inspect.Parameter.POSITIONAL_OR_KEYWORD)
                   or p.default is not inspect.Parameter.empty for p in parameters)):
        raise TypeError("model.forward must take exactly four positional arguments (raw, controls, duration, grid)")
    encoder_dim = getattr(model, "encoder_dim", None)
    if type(encoder_dim) is not int or encoder_dim <= 0:
        raise TypeError("model must expose a positive integer encoder_dim")


def temporal_predictions(model: nn.Module, raw_z: Tensor, controls: ActionSegments,
                         tau: Tensor, sigma: Tensor, grid: GridSpec) -> TemporalPredictions:
    """式15，同 losses.temporal_predictions：direct=Phi(Z,u1⊕u2,tau+sigma)，intermediate=Phi(Z,u1,tau)，
    composed=Phi(intermediate,u2,sigma)；三次完整前向，中间反馈不 LN、不 detach。"""
    _require_predictor(model)
    if not isinstance(controls, ActionSegments):
        raise TypeError("controls must be ActionSegments")
    if not isinstance(grid, GridSpec):
        raise TypeError("grid must be a GridSpec")
    _temporal_raw_contract(raw_z, "raw_z")
    grid.__post_init__()
    _temporal_time_contract(tau, "tau", raw_z.shape[0])
    _temporal_time_contract(sigma, "sigma", raw_z.shape[0])
    pair = split_action_segments(controls, tau=tau, sigma=sigma)
    long_controls = concatenate_action_segments(pair.first, pair.second)
    total = tau+sigma
    direct = model(raw_z, long_controls, total, grid)
    intermediate = model(raw_z, pair.first, tau, grid)
    composed = model(intermediate, pair.second, sigma, grid)
    difference = direct-composed
    if not torch.isfinite(difference).all():
        raise ValueError("temporal raw float32 difference must remain finite")
    return TemporalPredictions(direct, intermediate, composed, difference, tau.clone(), sigma.clone(),
                               input_scale(raw_z))


def spatial_predictions(model: nn.Module, raw_z: Tensor, controls: ActionSegments,
                        duration: Tensor, transfer: SpatialTransfer) -> SpatialPredictions:
    """式16，同 losses.spatial_predictions：restricted=R Phi(Z, source)，coarse=Phi(RZ, target)；两次完整前向。"""
    _require_predictor(model)
    if not isinstance(controls, ActionSegments):
        raise TypeError("controls must be ActionSegments")
    if not isinstance(transfer, SpatialTransfer):
        raise TypeError("transfer must be a SpatialTransfer")
    transfer.__post_init__()
    _temporal_raw_contract(raw_z, "raw_z")
    if (raw_z.shape[1] != transfer.source.height*transfer.source.width
        or raw_z.shape[2] != model.encoder_dim):
        raise ValueError("raw_z N/E must match transfer.source and model.encoder_dim")
    _temporal_time_contract(duration, "duration", raw_z.shape[0])
    fine_prediction = model(raw_z, controls, duration, transfer.source)
    restricted_prediction = apply_spatial_transfer(fine_prediction, transfer)
    _temporal_raw_contract(restricted_prediction, "restricted_prediction")
    coarse_z = apply_spatial_transfer(raw_z, transfer)
    _temporal_raw_contract(coarse_z, "coarse_z")
    coarse_prediction = model(coarse_z, controls, duration, transfer.target)
    difference = restricted_prediction-coarse_prediction
    if not torch.isfinite(difference).all():
        raise ValueError("spatial raw float32 difference must remain finite")
    return SpatialPredictions(restricted_prediction, coarse_prediction, difference,
                              duration.clone(), transfer.target, input_scale(raw_z))
```

- 签名检查只看形状不看名字：POJEPA 的 `forward` 第一个参数叫 `raw_z`，`TokenTransformer` 的叫 `raw`，两个都要通过。`inspect.signature(model.forward)` 取的是绑定方法，不含 `self`。
- `encoder_dim` 是 `spatial_predictions` 本来就读的属性（POJEPA、TokenTransformer 都有）；`bool` 不算整数（`type(...) is not int`）。
- 对 POJEPA，两个函数和 `losses.py` 的原函数逐位相同（同样的调用、同样的顺序），所以 S10 可以对所有模型都用这个模块；但 v7 条件和 po_jepa 类的新条件仍走 `losses.py` 的原函数（`training.train_step` 不改）。
- 不在 `losses.py` 里加任何东西，也不改 `losses.py` 的 `isinstance` 检查（`losses.temporal_predictions` 对 TokenTransformer 仍报 `model must be a POJEPA`，§3.7.3 核对）。

### 3.6 新文件 `src/po_jepa/ln_metrics.py`（10 §3.1）

全文如下（62 行，以一个换行结尾）：

```python
"""10 §3.1：同一网格上两个预测之间的逐样本差异，两种度量，float64 计算。

rms_ln(a, b)           = sqrt( sum_(N,E) (LN(a) - LN(b))^2 / (N*E) )
rms_input_scale(a, b, raw_z) = sqrt( sum_(N,E) (a - b)^2 / (N*E) ) / sqrt(s^2)，s^2 = losses.input_scale(raw_z)

LN 与 JEPA 损失的定义相同（逐 token 沿 E、总体方差、eps=1e-5、无仿射），但在 float64 上算。
a、b 先各自转 float64 再相减。两者都无量纲、返回与输入同设备的 float64 [B]、不带梯度；
不除时间（tcd_ln、scd_ln、分割差异的时间归一化由调用者做，10 §3.2–§3.5）。
"""

import torch
from torch import Tensor
from torch.nn import functional as F

from .losses import input_scale

LN_EPSILON = 1e-5


def _pair(a: Tensor, b: Tensor) -> None:
    """a、b：同形 [B,N,E]（三轴都为正）、都是 float32、同一设备、全部有限。"""
    for name, value in (("a", a), ("b", b)):
        if not isinstance(value, Tensor):
            raise TypeError(f"{name} must be a tensor")
    if (a.is_nested or b.is_nested or a.layout != torch.strided or b.layout != torch.strided
            or a.ndim != 3 or any(size <= 0 for size in a.shape) or a.shape != b.shape):
        raise ValueError("a and b must be dense tensors with the same shape [positive B, positive N, positive E]")
    if a.dtype != torch.float32 or b.dtype != torch.float32 or a.device != b.device or a.is_meta:
        raise ValueError("a and b must both be float32 on the same real device")
    if not torch.isfinite(a).all() or not torch.isfinite(b).all():
        raise ValueError("a and b must contain finite values")


def _rms(d64: Tensor) -> Tensor:
    """sum_(N,E) d^2/(N*E) 再开方，与 metrics._norm_ratio(rms=True) 的分子同一写法。"""
    return (d64.square().sum(dim=(1, 2))/(d64.shape[1]*d64.shape[2])).sqrt()


@torch.no_grad()
def rms_ln(a: Tensor, b: Tensor) -> Tensor:
    """RMS_LN(a, b)：跨模型（含 AC）比较用。float64 [B]，与输入同设备。"""
    _pair(a, b)
    e = a.shape[-1]
    la = F.layer_norm(a.detach().to(dtype=torch.float64), (e,), eps=LN_EPSILON)
    lb = F.layer_norm(b.detach().to(dtype=torch.float64), (e,), eps=LN_EPSILON)
    return _rms(la-lb)


@torch.no_grad()
def rms_input_scale(a: Tensor, b: Tensor, raw_z: Tensor) -> Tensor:
    """RMS_in(a, b)：对照理论用。raw_z 是 16×16 起点 [B,N0,E]（N0 可以和 a 的 N 不同），s^2 = losses.input_scale(raw_z)。"""
    _pair(a, b)
    if not isinstance(raw_z, Tensor):
        raise TypeError("raw_z must be a tensor")
    if (raw_z.is_nested or raw_z.layout != torch.strided or raw_z.ndim != 3 or raw_z.shape[1] <= 0
            or raw_z.shape[0] != a.shape[0] or raw_z.shape[2] != a.shape[2]
            or raw_z.dtype != torch.float32 or raw_z.device != a.device):
        raise ValueError("raw_z must be a dense float32 [B, positive N0, E] tensor with a's B and E on a's device")
    if not torch.isfinite(raw_z).all():
        raise ValueError("raw_z must contain finite values")
    d64 = a.detach().to(dtype=torch.float64)-b.detach().to(dtype=torch.float64)
    return _rms(d64)/input_scale(raw_z).sqrt()
```

已定的几点（§9 第 3、4、12 条）：

- **先各自转 float64 再相减**（10 §3.1 “float64 计算”）。v7 的 `tcd_rms` 用的是 float32 的差（`direct-composed`）再转 float64，所以 `rms_input_scale(direct, composed, raw)/(τσ)` 和 v7 的 `tcd_normalized` 不是逐位相同，相对差的上界是 float32 相减的舍入 2⁻²⁴ ≈ 6e-8，实测最大 3.2e-9（§3.7.4 要求 ≤ 1e-7）。
- **LN 定义和 JEPA 损失相同、在 float64 上算**：`F.layer_norm(x.double(), (E,), eps=1e-5)`，总体方差、无仿射。JEPA 损失自己的 LN 在 float32 上算，这里不复用它。
- 输入只收 float32（模型输出和编码器特征都是 float32），返回值和输入同设备、无梯度、不做时间归一化。`raw_z` 的 N0 可以和 a、b 的 N 不同（跨网格的 xpd 在 8×8 上算，但用 16×16 起点的 s²，10 §3.4）。s² 不合法（例如常数输入）时报 `losses.input_scale` 自己的错。

```python
    spatial = module.spatial_predictions(model, raw, controls, duration, transfer)

def transformer_case():

    with torch.random.fork_rng(devices=[]):

class Scripted(nn.Module):
    """第 i 次前向返回常数场 values[i]（形状同输入）；用来造出差值溢出。"""
    encoder_dim = 32
    def __init__(self, values):
        super().__init__()
        self.values, self.calls = list(values), 0
    def forward(self, raw, controls, duration, grid):
        value = self.values[self.calls]
        self.calls += 1
        return torch.full_like(raw, value)
```

```python
def hand_ln(x):
    x = x.astype(np.float64)
    mean = x.mean(axis=-1, keepdims=True)
    var = ((x-mean)**2).mean(axis=-1, keepdims=True)
```

```python
def spectrum_for(self, source: Tensor, grid: GridSpec, *, k: int, model_device: torch.device) -> SpectralResult
```

- `POJEPA.prepare_query` 每次查询恰好调用一次：`self.spectrum.spectrum_for(raw_z if graph.affinity_source == "encoder" else x, grid, k=modes, model_device=x.device)`，在 `fixed_modes` 检查和 `modes` 之后。`prepare_query` 仍然读 `self.spectrum.config` 的 `affinity_source`、`fixed_modes`、`max_modes`，所以重写它的子类也要有这样的 `config`（08 §4 的 `FourierConfig(GraphConfig)` 满足）。
- 返回 `SpectralResult(eigenvalues_cpu, basis_cpu, eigenvalues, basis, diagnostics)`：`eigenvalues_cpu` [B,k]、`basis_cpu` [B,N,k] 是 CPU float64；`eigenvalues`、`basis` 同形、在 `model_device` 上的 float32；都不带梯度；`diagnostics` 是 `SpectralDiagnostics`。S10 的 `FourierSpectrum.spectrum_for` 要返回同样的类型、形状、dtype 和设备（`source` 只用来取 B、N 和设备）。

### 4.2 损失标签（`training._loss_config`）

| 标签 | 接受的权重 | 不符时的报错（`ValueError`） | 用于 |
|---|---|---|---|
| `"full"` | 两个都 > 0 | `condition must be full with two positive weights or no_consistency with two zero weights` | v7 po_jepa_full、fixed_fourier、transformer_consistency 的检查点 |
| `"no_consistency"` | 两个都 = 0 | 同上 | v7 |
| `"time_only"` | time > 0，space = 0 | `condition time_only requires a positive time weight and a zero space weight` | po_jepa_time_only |
| `"space_only"` | time = 0，space > 0 | `condition space_only requires a zero time weight and a positive space weight` | po_jepa_space_only |
| 其他字符串 | — | v7 那一句 | — |

`-0.0` 算 0。返回值是 `LossConfig` 的原生快照（`float`/`str`）。`train_step(..., condition=label)`、`save_training_checkpoint(..., condition=label)`、`load_training_checkpoint(..., condition=label)` 直接用，检查点的 `condition` 字段存标签。

### 4.3 一致性监控（`runtime.comparison`）

```python
def monitored_consistency_terms(condition: str, loss_config) -> tuple[str, ...] | None
def consistency_monitor_summary(output, condition, loss_config, target_rho=None) -> dict | None   # 签名不变
def early_check(output, condition, loss_config, completed, target_rho=None) -> None               # 签名不变
```

- `monitored_consistency_terms`：`"po_jepa_full"` → `("time", "space")`（不读 `loss_config`）；`V7_CONDITIONS` 里的其他名字和 `"identity"` → None（不读 `loss_config`）；其他名字：`loss_config` 不是 `LossConfig` 报 `TypeError("loss_config must be a LossConfig")`，否则按 time、space 的顺序取权重 > 0 的项，一项都没有返回 None。按 08 §1 的权重：time_only → `("time",)`，space_only → `("space",)`，transformer_consistency、fixed_fourier → `("time", "space")`，koopman → None。
- po_jepa_full 的汇总和 v7 完全相同（键序 `measurements, rho, threshold, median_share, active`；空时 `measurements, rho, active, median_share, threshold`）。
- 新条件的汇总：`dict(measurements, rho, threshold, median_share, active, checked_terms)`，`median_share` 只含 `checked_terms` 里的项，`active = all(这些项的中位数 >= monitoring.min_share)`，`checked_terms` 是 list（例如 `["time"]`）；没有测量时 `dict(measurements=0, rho, active=False, median_share=None, threshold, checked_terms)`。`early-check.json` 是 `dict(completed_updates=…, **汇总)`，用 `cache._write_json` 写（键排序）。
- 读的数据：`<output>/updates/*.json` 的 `completed_updates` 和 `consistency_gradient.share.<项>`（S10 的 `consistency_share` 对新条件要给出被检查的项）；协议的 `calibration.rho`、`monitoring.min_share`、`monitoring.early_check_updates`。

### 4.4 `po_jepa.generic_consistency`

```python
def temporal_predictions(model: nn.Module, raw_z: Tensor, controls: ActionSegments, tau: Tensor, sigma: Tensor, grid: GridSpec) -> losses.TemporalPredictions
def spatial_predictions(model: nn.Module, raw_z: Tensor, controls: ActionSegments, duration: Tensor, transfer: SpatialTransfer) -> losses.SpatialPredictions
```

- `model` 要求：`nn.Module`；`forward` 恰好 4 个没有默认值的位置参数 `(raw, controls, duration, grid)`，返回 float32 [B,N,E]；有正整数 `encoder_dim`（等于 E）。S10 的 `KoopmanPredictor` 若要用它，也要满足这三条。
- 前向次数：时间 3 次（direct、intermediate、composed，都在 `grid` 上），空间 2 次（`transfer.source` 上 1 次、`transfer.target` 上 1 次）。返回值交给 `losses.temporal_consistency_loss`、`spatial_consistency_loss`、`weighted_total_loss`。
- `direct` 用的是切开再拼接的动作 u1⊕u2，transformer_consistency 的 JEPA 项不能复用它（08 §3），要另做一次原动作、原时长的前向。

### 4.5 `po_jepa.ln_metrics`

```python
LN_EPSILON = 1e-5
def rms_ln(a: Tensor, b: Tensor) -> Tensor                         # float64 [B]，同设备，无梯度
def rms_input_scale(a: Tensor, b: Tensor, raw_z: Tensor) -> Tensor  # float64 [B]，同设备，无梯度
```

- `a`、`b`：同形 float32 [B,N,E]、同设备、有限；`raw_z`：float32 [B,N0,E]，N0 可以和 N 不同。
- 都不除时间。S18 按 10 §3 自己归一化：`tcd_ln = rms_ln(Φ_T(z), Φ_{T/2}∘Φ_{T/2}(z))/(T/2)²`；`scd_ln = rms_ln(RΦ¹⁶_T(z), Φʰ_T(Rz))/T`；分割差异 pd 两种都报、不除；xpd 在 8×8 上算，`rms_input_scale` 的 `raw_z` 传 16×16 起点；`tcd_unequal` 除以 τσ。
- 10 §3.3 “等分 2 段的 pd 和同一时长的 TCD 结果必须一致”：对同一对张量调同一个函数结果逐位相同，所以 S18 复用同一对预测即可；`rms_input_scale(...)/(τσ)` 和 v7 的 `tcd_normalized` 只在相对 1e-7 内一致，不是逐位。
