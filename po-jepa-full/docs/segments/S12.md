## 3. 接口

- 模型：`model(raw [B,256,E] float32, controls, duration CPU float64 [B], grid=regular_grid(16,16)) -> [B,256,E]`，和其他评测轴相同。
- AC：可选 `bind(model, start_state CPU float64 [B,7], reference=这批的 controls) -> predictor`，predictor 签名同上。
- 代价：`losses.jepa_distance(pred.float(), target, config=loss_config).per_sample`（float32），`torch.no_grad`（jepa_distance 不收 inference 张量）。
- 候选动作：真实动作 + 63 个干扰项窗口自己的物理动作（`action_<source>[s′ : s′+d]`），都放在窗口 w 的时间轴上（起点 s，每周期一段），走 `window_controls`。
