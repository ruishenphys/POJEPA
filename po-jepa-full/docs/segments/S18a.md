#### 3.1.1 `addon/long_window.py`（42 行）

10 §3.7 的读窗口函数。`cache.read_window` 只收 T ∈ {1, 2, 3, 4, 8, 12}、起点 0–20，长时程要 T ∈ {16, 24, 32}、起点 0；规格要求不改 `read_window`，所以复制它的函数体，只换两条参数检查，并加“不超过最后一帧”的检查。复制部分和 `read_window` 逐字段逐位相同，测试把 LONG_TIMES 临时放宽到短时长后两边逐字段比较（`test_body_equals_read_window`）。

```python
"""10 §3.7：D4 长时程窗口（T = 16、24、32）的读取。

和 cache.read_window 相同，只有时长和起点的检查不同：时长只收 16、24、32 个周期，起点是非负整数 tick，
并要求 start_tick + T 不超过缓存的最后一帧（仿真轨迹 33 帧，最后一帧是第 32 个 tick）。读缓存、转 float32、
裁动作、组窗口的写法逐行照抄 cache.read_window，复用 cache._read_complete_cache 和 cache._window_controls；
cache.read_window 本身不改。
"""

from pathlib import Path

import numpy as np

import torch

from .. import cache

LONG_TIMES = (16., 24., 32.)


def read_long_window(path, *, start_tick, duration_cycles, expected_split, device):
    """读明确 ID 缓存的起点帧和第 start_tick+T 帧，返回 cache.CacheWindow（字段、精度、设备和 read_window 相同）。"""
    if type(start_tick) is not int or start_tick < 0:
        raise ValueError("long-horizon start must be a nonnegative integer tick")
    if type(duration_cycles) not in (int, float) or duration_cycles not in LONG_TIMES:
        raise ValueError("long-horizon duration must be 16, 24 or 32 cycles")
    raw, m, manifest_sha = cache._read_complete_cache(Path(path)); end = int(start_tick+duration_cycles)
    if end > raw.shape[0]-1:
        raise ValueError("long-horizon window runs past the last cached frame")
    if m["split"] != expected_split:
        raise ValueError("cross-split cache/window request")
    with torch.inference_mode(False), torch.no_grad():
        z = torch.from_numpy(np.array(raw[start_tick:start_tick+1], dtype=np.float32, copy=True)).to(device).clone()
        target = torch.from_numpy(np.array(raw[end:end+1], dtype=np.float32, copy=True)).to(device).clone()
        duration = torch.tensor([float(duration_cycles)], dtype=torch.float64, device="cpu")
        observed = torch.tensor([start_tick*.25], dtype=torch.float64, device="cpu")
        controls = cache._window_controls(m, start_tick, float(duration_cycles), device)
        inputs = cache.WindowInput(z, controls, duration, cache.regular_grid(16, 16), observed,
            m["frames"][start_tick]["image_sha256"], m["trajectory_id"], m["split"])
        label = cache.WindowTarget(target, torch.tensor([end*.25], dtype=torch.float64, device="cpu"), m["frames"][end]["image_sha256"])
    provenance = dict(actual_manifest_sha256=manifest_sha, generation=m["generation"], preprocess_sha256=m["preprocess_sha256"],
        observation_variant=m["observation_variant"])
    return cache.CacheWindow(inputs, label, provenance)
```

```python
                or payload.get("spec") != spec or spec != asdict(model.spec)):
            raise ValueError(f"{condition} checkpoint schema/condition/spec differs from ac_baseline.spec_for")

    raise ValueError(f"condition {condition} has no checkpoint")

    return dict(record, training_dir=str(root), best=dict(step=best["step"], mean=best["mean"], checkpoint=best["checkpoint"],
                checkpoint_sha256=best["checkpoint_sha256"]), checkpoint=snapshot, data_fields=found,
                source_files_sha256=provenance["source_files_sha256"])
```

#### 3.1.3 `addon/d4.py`（420 行）

文件头的表就是 10 §3.2–§3.7 的全部量和归一化。几处实现上的选择：

- **Φ_T 只算一次**：每个时长 T 先按 v7 `point_metrics` 的 3 行算 `direct`（在 T/2 处切开再接上，`direct_prediction`）和它的两半组合（`direct_pair`），tcd_ln、pd、xpd 的细网格一侧、tcd_unequal、留出分解都用这同一个 `direct` 张量；2 段等分的 pd 直接复用 tcd 的那一对（10 §3.3 末段允许），所以 `pd_ln:T=4:2x2 / 4 == tcd_ln:T=4` 逐位成立（测试核）。scd_ln 用 v7 `pair_metrics` 的那一对（动作不切开）。这样等价核对的三项和 D4 的量来自同一批张量（§9 第 1 条）。
- **分割滚动** `rollout`：每段一次完整调用，下一段的输入是上一段的原始输出；动作用 `pieces` 依次 `split_action_segments(rest, τ_i, 剩余时长)`，所以每段的局部时间从 0 开始、物理原点跟着前移（测试核）。
- **每个窗口 92 次调用**（tcd 18、scd 24、pd 26、xpd 12、不等分 8、留出 4），长时程每条轨迹 12 次（10 §3.10 的估计是 80–100、12）。调用顺序固定（测试 `test_call_plan_and_rollout_order` 逐个核）。
- **度量**：LN 空间和输入尺度都用 S08a 的 `ln_metrics`（float64），输入尺度的 s² 一律用 16×16 起点（xpd 也是，10 §3.1）；JEPA 距离用 `comparison.jepa_distance(...).per_sample`（float32，和 v7 的 `future_jepa_distance` 相同）。
- **等价核对**：同一窗口上用 v7 `point_metrics`、`pair_metrics` 的写法重算 `future_jepa_distance`、`tcd_normalized`、`scd_normalized`（24 个值），和被读任务的 `evaluation/<条件>/rows/*.json` 比；被读任务的 `evaluation/<条件>/` 必须有 `COMPLETE.json`、没有 `FAILED.json`，`registration.json` 的查询列表必须等于当前 `evaluation.build_index()`（§9 第 7 条）。判据只用容差 1e-6·max(1, |旧|)；逐位相同的条数只报告（`float.hex()` 相同）。
- **三角不等式**按 10 §3.6 的式子带 1e-6·max(1, direct) 的容差；违反数不为 0 任务失败。
- 任务入口 `run_d4` 按 10 §7 写目录；全部核对通过才写 `COMPLETE.json`，否则写 `report.json`（`status: "failed"`）和 `FAILED.json` 再报 `ValueError`。评测前后用 v7 的 `_state_identity` 核参数、梯度、buffer 没变，并恢复每个子模块的 train/eval 标志。

```python
def _t(value) -> str:
    """时长写进键名：1.0 → "1"、0.5 → "0.5"、12.0 → "12"。"""

def partition_label(parts) -> str:
    """等分写成 "段数x每段"（2x2、4x1、8x0.5），其余写成 "τ1+τ2+…"（3+5、1+3）。"""
    if len(parts) > 1 and len(set(parts)) == 1:

def _cycles(value) -> torch.Tensor:
    return torch.tensor([float(value)], dtype=torch.float64)


def pieces(controls, parts) -> list:
    """把时长 Σparts 的动作依次精确切成 len(parts) 段：第 i 次 split_action_segments(rest, τ_i, 剩余时长)。"""
    out, rest = [], controls
    for i, tau in enumerate(parts[:-1]):
        pair = comparison.split_action_segments(rest, tau=_cycles(tau), sigma=_cycles(sum(parts[i+1:])))
        out.append(pair.first)
        rest = pair.second
    out.append(rest)
    return out


def rollout(model, raw, controls, parts, grid):
    """Φ_Π(raw)：逐段完整调用，下一段的输入是上一段输出的原始预测（不 LN、不用真实中间帧）。"""
    x = raw
    for piece, tau in zip(pieces(controls, parts), parts):
        x = model(x, piece, _cycles(tau), grid)
    return x


def direct_prediction(model, window):
    """Φ_T(z)：v7 evaluation.point_metrics 的前 3 行原样（在 T/2 处切开再接上）。返回 (direct, pair, tau)。"""
    raw, grid = window.inputs.raw_z, window.inputs.grid
    controls, duration = window.inputs.controls, window.inputs.duration
    tau = duration*.5
    pair = comparison.split_action_segments(controls, tau=tau, sigma=tau)
    direct = model(raw, comparison.concatenate_action_segments(pair.first, pair.second), duration, grid)
    return direct, pair, tau


def direct_pair(model, window):
    """v7 evaluation.point_metrics 的 direct、first、composed 4 行：返回 (direct, first, composed, tau)。"""
    raw, grid = window.inputs.raw_z, window.inputs.grid
    direct, pair, tau = direct_prediction(model, window)
    first = model(raw, pair.first, tau, grid)
    composed = model(first, pair.second, tau, grid)
    return direct, first, composed, tau


def _ln(a, b) -> float:

def _in(a, b, raw16) -> float:

def _jepa(a, b, config) -> float:

        values[f"tcd_ln:T={_t(t)}"] = _ln(d, composed)/((t/2)**2)
        direct[t], half[t] = d, composed
    for t in TCD_TIMES:                                                    # 10 §3.2 scd_ln；§4.3 scd_normalized
        w = windows[t]
        raw, controls, duration = w.inputs.raw_z, w.inputs.controls, w.inputs.duration
        for h in SCD_GRIDS:
            transfer = comparison.build_spatial_transfer(w.inputs.grid, target_height=h, target_width=h)
            fine = comparison.apply_spatial_transfer(model(raw, controls, duration, transfer.source), transfer)
            coarse = model(comparison.apply_spatial_transfer(raw, transfer), controls, duration, transfer.target)
            record = comparison.SpatialPredictions(fine, coarse, fine-coarse, duration.clone(), transfer.target)
            scd_rms = float(metrics.spatial_commutation_rms_defect(record).values[0])
            equivalence[f"scd_normalized:h={h}:T={_t(t)}"] = scd_rms/math.sqrt(float(comparison.input_scale(raw)[0]))
            values[f"scd_ln:h={h}:T={_t(t)}"] = _ln(fine, coarse)/t
    for t, parts in PARTITIONS:                                            # 10 §3.3
        w = windows[t]
        raw = w.inputs.raw_z
        composed = half[t] if parts == (t/2, t/2) else rollout(model, raw, w.inputs.controls, parts, w.inputs.grid)
        label = partition_label(parts)
        values[f"pd_ln:T={_t(t)}:{label}"] = _ln(direct[t], composed)
        values[f"pd_in:T={_t(t)}:{label}"] = _in(direct[t], composed, raw)
    for t, n in CROSS:                                                     # 10 §3.4
        w = windows[t]
        raw = w.inputs.raw_z
        transfer = comparison.build_spatial_transfer(w.inputs.grid, target_height=8, target_width=8)
        fine = comparison.apply_spatial_transfer(direct[t], transfer)
        coarse = rollout(model, comparison.apply_spatial_transfer(raw, transfer), w.inputs.controls, (t/n,)*n, transfer.target)
        values[f"xpd_ln:T={_t(t)}:n={n}"] = _ln(fine, coarse)
        values[f"xpd_in:T={_t(t)}:n={n}"] = _in(fine, coarse, raw)
    for d, parts in UNEQUAL:                                               # 10 §3.5
        w = windows[d]
        raw = w.inputs.raw_z
        composed = rollout(model, raw, w.inputs.controls, parts, w.inputs.grid)
        label = partition_label(parts)
        scale = parts[0]*parts[1]
        values[f"tcd_unequal_ln:d={_t(d)}:{label}"] = _ln(direct[d], composed)/scale
        values[f"tcd_unequal_in:d={_t(d)}:{label}"] = _in(direct[d], composed, raw)/scale
    triangle = {}
    for t, parts in HELDOUT:                                               # 10 §3.6
        w = windows[t]
        composed = rollout(model, w.inputs.raw_z, w.inputs.controls, parts, w.inputs.grid)
        target = w.target.raw_z
        a, b, c = _jepa(direct[t], target, config), _jepa(direct[t], composed, config), _jepa(composed, target, config)
        values[f"heldout_direct:T={_t(t)}"] = a
        values[f"heldout_partition:T={_t(t)}"] = b
        values[f"heldout_rollout:T={_t(t)}"] = c
        triangle[f"T={_t(t)}"] = triangle_holds(a, b, c)
    if tuple(values) != value_names() or tuple(equivalence) != equivalence_names():
        raise RuntimeError("D4 value names differ from the registered order")
    return _finite(values), _finite(equivalence), triangle

def compare_equivalence(new, old):
    """一个值的等价核对：返回 (在容差内, 逐位相同, 绝对差, 相对差或 None)。"""
    if type(old) not in (int, float) or not math.isfinite(old):
        raise ValueError("reference value must be a finite number")
    old = float(old)
    difference = abs(new-old)
    return (difference <= EQUIVALENCE_TOLERANCE*max(1., abs(old)), new.hex() == old.hex(), difference,
            difference/abs(old) if old != 0 else None)


def triangle_holds(direct, partition, rollout_value) -> bool:
    """10 §3.6 的核对：direct ≤ partition + rollout + 1e-6·max(1, direct)。"""
    return direct <= partition+rollout_value+TRIANGLE_TOLERANCE*max(1., direct)

def reference_rows(job_dir, condition):
    """被读任务自己的标准评测记录：{(kind, 轨迹, 起点, 时长, 网格): values}。查询列表必须和当前 build_index 相同。"""

def _reference_value(reference, tid, start, name):
    metric, *rest = name.split(":")
    fields = dict(item.split("=") for item in rest)
    t = float(fields["T"])
    key = ("pair", tid, start, t, int(fields["h"])) if metric == "scd_normalized" else ("point", tid, start, t, 16)
    if key not in reference or metric not in reference[key]:
        raise ValueError(f"reference row missing for {key} {metric}")
    return reference[key][metric]


def _macro(rows, names):
    """轨迹宏平均：先在每条轨迹内对窗口平均，再在轨迹间平均（13 §3 的前两层）。"""
    by_trajectory = {}
    for row in rows:
        by_trajectory.setdefault(row["trajectory_id"], []).append(row["values"])
    out = {}
    for name in names:
        means = [sum(v[name] for v in group)/len(group) for group in by_trajectory.values()]
        out[name] = sum(means)/len(means) if means else None
    return out


def run_d4(features, output, device, condition, *, training_run):
    """一个 D4 任务：读 training_run 的选中检查点（10 §4.2），在全部测试窗口和测试轨迹上算 §3 的量和 §4.3 的等价核对，
    按 10 §7 写 output（必须是新目录）。全部核对通过才写 COMPLETE.json，否则写 FAILED.json 并报 ValueError。"""
    if condition not in v7load.D4_CONDITIONS:
        raise ValueError(f"--condition 必须是 {v7load.D4_CONDITIONS} 之一")
    features, output = Path(features), Path(output)
    output.mkdir(parents=True, exist_ok=False)
    job_dir = Path(training_run).resolve()
    from ..v7jobs import _job_dir
    job_dir = _job_dir(job_dir)
    job = dict(kind="d4", condition=condition, dataset=data.datasets.active().tag, seed=checks.model_seed(),
               updates=checks.v7_updates(), training_run=str(Path(training_run).resolve()), job_dir=str(job_dir))
    cache._write_json(output/"job.json", job)
    cache._write_json(output/"runtime.json", environment.runtime_signature(device))
    stage = "load"
    try:
        model, loss = comparison.build_condition(condition, device)
        source = v7load.load_v7_selected(job_dir, condition, model, loss_config=loss, features=features, device=device)
        cache._write_json(output/"source.json", source)
        reference = reference_rows(job_dir, condition)
        (output/"rows").mkdir()
        (output/"long").mkdir()
        modes = {m: m.training for m in model.modules()}
        identity = evaluation._state_identity(model)
        rows, longs = [], []
        stats = {m: dict(count=0, bitwise_equal=0, max_abs_diff=0., max_rel_diff=0., outside_tolerance=0) for m in EQUIVALENCE_METRICS}
        violations = []
        try:
            model.eval()
            stage = "windows"
            for index, (tid, start) in enumerate(windows_index()):
                windows = {t: evaluation.load_test_window(features, evaluation.EvaluationQuery(tid, start, t, 16, "point"), device)
                           for t in TCD_TIMES}
                values, new, triangle = window_values(model, windows, loss)
                pairs = {}
                for name, value in new.items():
                    old = _reference_value(reference, tid, start, name)
                    ok, bitwise, difference, relative = compare_equivalence(value, old)
                    entry = stats[name.split(":")[0]]
                    entry["count"] += 1; entry["bitwise_equal"] += bitwise; entry["outside_tolerance"] += not ok
                    entry["max_abs_diff"] = max(entry["max_abs_diff"], difference)
                    entry["max_rel_diff"] = max(entry["max_rel_diff"], relative or 0.)
                    pairs[name] = dict(new=value, old=float(old), within_tolerance=ok)
                for key, ok in triangle.items():
                    if not ok:
                        violations.append(dict(index=index, trajectory_id=tid, start_tick=start, heldout=key))
                row = dict(index=index, trajectory_id=tid, start_tick=start, values=values, equivalence=pairs,
                           triangle_ok=triangle, manifest_sha256=windows[1.].provenance["actual_manifest_sha256"])
                cache._write_json(output/"rows"/f"{index:05d}.json", row)
                rows.append(row)
            stage = "long"
            for tid in data.datasets.active().split_range("test"):
                windows = {t: load_long_test_window(features, tid, t, device) for t in LONG_TIMES}
                row = dict(trajectory_id=tid, start_tick=0, values=long_values(model, windows, loss),
                           manifest_sha256=windows[LONG_TIMES[0]].provenance["actual_manifest_sha256"])
                cache._write_json(output/"long"/f"{tid:04d}.json", row)
                longs.append(row)
        finally:
            for module, flag in modes.items():
                module.training = flag
        if evaluation._state_identity(model) != identity:
            raise RuntimeError("D4 changed parameters, gradients or buffers")
        failed = [m for m, s in stats.items() if s["outside_tolerance"]]
        problems = ([f"equivalence outside tolerance: {failed}"] if failed else []) + \
                   ([f"triangle inequality violated in {len(violations)} cases"] if violations else [])
        long_means = {}
        for name in long_value_names():
            vals = [r["values"][name] for r in longs]
            long_means[name] = sum(vals)/len(vals) if vals else None
        report = dict(job=job, status="failed" if problems else "passed", problems=problems,
                      counts=dict(windows=len(rows), long_trajectories=len(longs), test_trajectories=len({r["trajectory_id"] for r in rows})),
                      equivalence=dict(tolerance=EQUIVALENCE_TOLERANCE, passed=not failed, metrics=stats),
                      triangle=dict(tolerance=TRIANGLE_TOLERANCE, violations=len(violations), cases=violations),
                      trajectory_macro_means=_macro(rows, value_names()), long_means=long_means,
                      definitions=definitions(), device=str(device), scientific_conclusions_verified=False)
        cache._write_json(output/"report.json", report)
        if problems:
            raise ValueError("; ".join(problems))
        cache._write_json(output/"COMPLETE.json", dict(report_sha256=cache.file_sha(output/"report.json")))
        return report
    except Exception as error:
        cache._write_json(output/"FAILED.json", dict(stage=stage, error_type=type(error).__name__, message=str(error)))
        raise
```

#### 3.1.4 `addon/spectral_gap.py`（105 行）

每个场景一次，CPU。图用协议的 `model.graph`（`checks.build_full_model(config, cpu).spectrum`，σ_z 来自 v7 标定），K = `max_modes`（16），在 16×16、8×8、12×12 上各求一次。λ_{K+1} = λ_K + `cutoff_gap`（`spectrum_for` 本身只返回前 K 个特征值；测试用稠密 `eigvalsh` 核这一点）。输出文件名用 `report.json`（和 D 任务、D4 任务相同，S18b 的汇总按 `job.json + COMPLETE.json + report.json` 找任务，§9 第 11 条）。

```python
"""10 §5：截断间隙（run.py spectral-gap 的计算部分，CPU，每个场景一次）。

图只由编码器特征、Q（种子 1703）、σ_x 和本场景的 σ_z 决定，和条件、种子无关。对全部测试窗口的起点帧，在
16×16（z）、8×8（R z）、12×12（R z）上用 po_jepa_full 的 GraphSpectrum.spectrum_for 求最低 K 个特征对
（K = 协议的 model.graph.max_modes，仿真 16），每个窗口每个网格记：

- lambda_k = λ_K（eigenvalues_cpu 的最后一个），lambda_k1 = λ_K + cutoff_gap（= λ_{K+1}），
- cutoff_gap = diagnostics.cutoff_gap（λ_{K+1} − λ_K），
- median_gap = diagnostics.consecutive_gaps（前 K 个模态的 K−1 个相邻间隙）的中位数（statistics.median），
- ratio = cutoff_gap / median_gap；median_gap = 0 时为 None（计入 undefined_ratio，不进分位数）。

报告每个网格上这五个量的 5、25、50、75、95 分位数（torch.quantile，float64，linear 插值）。预先定好的规则：
每个网格上 ratio 的中位数（50 分位）都大于 1，论文保留原句；否则改成 “K = 16 is fixed in advance and shared
across grids”。fixed_fourier 的截断间隙由公式给出，恒为 0（08 §4.3），报告里单列一行。
"""

import statistics

from pathlib import Path

import torch

from .. import cache, checks, comparison, data, evaluation
from . import d4

GRIDS = (16, 8, 12)
QUANTILE_LEVELS = (.05, .25, .5, .75, .95)
FIELDS = ("lambda_k", "lambda_k1", "cutoff_gap", "median_gap", "ratio")
KEEP_SENTENCE = "keep the original sentence (median ratio > 1 on every grid)"
REWRITE = "K = 16 is fixed in advance and shared across grids"


def gap_record(result) -> dict:
    """一个 SpectralResult（批大小 1）→ 一条记录。"""
    eigenvalues = result.eigenvalues_cpu[0]
    if result.diagnostics.cutoff_gap is None:
        raise ValueError("K equals the number of tokens; the cutoff gap is undefined")
    cutoff = float(result.diagnostics.cutoff_gap[0])
    gaps = [float(g) for g in result.diagnostics.consecutive_gaps[0]]
    median = statistics.median(gaps)
    lam = float(eigenvalues[-1])
    return dict(lambda_k=lam, lambda_k1=lam+cutoff, cutoff_gap=cutoff, median_gap=median,
                ratio=cutoff/median if median > 0 else None)


def window_gaps(spectrum, raw_z, grid, k) -> dict:
    """一个窗口起点帧在三个网格上的记录：{"16": …, "8": …, "12": …}。"""
    out = {}
    for size in GRIDS:
        if size == 16:
            source, target = raw_z, grid
        else:
            transfer = comparison.build_spatial_transfer(grid, target_height=size, target_width=size)
            source, target = comparison.apply_spatial_transfer(raw_z, transfer), transfer.target
        out[str(size)] = gap_record(spectrum.spectrum_for(source, target, k=k, model_device=torch.device("cpu")))
    return out


def summarize(windows) -> dict:
    """每个网格上五个量的分位数、ratio 中位数是否大于 1，以及判断结果。"""
    grids, keep = {}, True
    for size in GRIDS:
        records = [w["grids"][str(size)] for w in windows]
        entry = dict(windows=len(records), undefined_ratio=sum(r["ratio"] is None for r in records))
        for name in FIELDS:
            values = [r[name] for r in records if r[name] is not None]
            entry[name] = (torch.quantile(torch.tensor(values, dtype=torch.float64),
                                          torch.tensor(QUANTILE_LEVELS, dtype=torch.float64)).tolist() if values else None)
        entry["median_ratio"] = entry["ratio"][2] if entry["ratio"] else None
        entry["median_ratio_above_1"] = entry["median_ratio"] is not None and entry["median_ratio"] > 1
        keep = keep and entry["median_ratio_above_1"]
        grids[str(size)] = entry
    return dict(quantile_levels=list(QUANTILE_LEVELS), grids=grids, keep_sentence=keep,
                decision=KEEP_SENTENCE if keep else REWRITE)


def run_spectral_gap(features, output, device):
    """一个场景的截断间隙：写 output/job.json、output/report.json、output/COMPLETE.json（output 必须是新目录）。
    文件名和 D 任务、D4 任务相同，汇总按 job.json + COMPLETE.json + report.json 找任务（13 §1）。"""
    if torch.device(device).type != "cpu":
        raise ValueError("spectral-gap runs on CPU (10 §5)")
    features, output = Path(features), Path(output)
    output.mkdir(parents=True, exist_ok=False)
    config = checks.load_protocol()
    graph = config["model"]["graph"]
    if not graph["fixed_modes"]:
        raise ValueError("spectral-gap expects a fixed K shared across grids")
    k = graph["max_modes"]
    job = dict(kind="spectral_gap", dataset=data.datasets.active().tag, updates=checks.v7_updates(), k=k)
    cache._write_json(output/"job.json", job)
    spectrum = checks.build_full_model(config, torch.device("cpu")).spectrum
    windows = []
    with torch.no_grad():
        for tid, start in d4.windows_index():
            w = evaluation.load_test_window(features, evaluation.EvaluationQuery(tid, start, 1., 16, "point"), "cpu")
            windows.append(dict(trajectory_id=tid, start_tick=start, manifest_sha256=w.provenance["actual_manifest_sha256"],
                                grids=window_gaps(spectrum, w.inputs.raw_z, w.inputs.grid, k)))
    report = dict(job=job, graph=dict(q_seed=graph["q_seed"], sigma_x=graph["sigma_x"], sigma_z=graph["sigma_z"],
                                      affinity_source=graph["affinity_source"], k=k),
                  windows=windows, summary=summarize(windows),
                  fixed_fourier=dict(cutoff_gap=0.0, note="08 §4.3: the DCT-II cutoff gap is zero by formula"),
                  scientific_conclusions_verified=False)
    cache._write_json(output/"report.json", report)
    cache._write_json(output/"COMPLETE.json", dict(report_sha256=cache.file_sha(output/"report.json")))
    return report
```

#### 3.1.5 `addon/encoder_identity.py` 和 `tools/encoder_identity.py`（84 行、43 行）

10 §6。官方 AC 权重的顶层键 `encoder`（和 `predictor`），fpc64-256 的顶层键 `target_encoder`（和 `encoder`）；主比较是 AC 的 `encoder` 对 fpc64-256 的 `target_encoder`（D4、v7 训练用的就是 `target_encoder`），其余配对也算、写进报告（§9 第 12 条）。逐位相同按存储字节比，不转精度。

```python
"""10 §6：官方 AC 权重 vjepa2-ac-vitg.pt 里自带的编码器，和我们用的 vjepa2-vitg-fpc64-256.pth 的 target_encoder
是不是同一份（CPU；入口 tools/encoder_identity.py，A0 段）。

两边的状态字典按 ac_baseline.load_official 的写法依次去掉 "module."、"backbone." 前缀（每个至多一次），去掉后
重名报错，然后按名字配对。比较对：AC 的 encoder（和 target_encoder，如果有）× fpc64-256 的 target_encoder（和
encoder，如果有）；主比较是 AC encoder 对 fpc64-256 target_encoder，结论 verdict 取主比较的：

- "missing_keys"：任一边有配不上的键；
- "different"：全部配上，但有张量形状或精度不同，或按存储精度不逐位相同；
- "same"：全部配上、形状和精度相同、全部逐位相同。

逐位相同按存储的字节比（reshape(-1) 后 view(torch.uint8)），不转精度；最大绝对差在形状相同的配对上用 float64 算。
"""

import torch

PREFIXES = ("module.", "backbone.")
AC_KEYS = ("encoder", "target_encoder")
ENCODER_KEYS = ("target_encoder", "encoder")
PRIMARY = ("encoder", "target_encoder")


def strip(state: dict) -> dict:
    cleaned = {}
    for key, value in state.items():
        for prefix in PREFIXES:
            if key.startswith(prefix):
                key = key[len(prefix):]
        if key in cleaned:
            raise ValueError(f"prefix collision after stripping: {key}")
        if not isinstance(value, torch.Tensor):
            raise TypeError(f"state entry {key} is not a tensor")
        cleaned[key] = value
    return cleaned


def _bytes_equal(a: torch.Tensor, b: torch.Tensor) -> bool:
    return torch.equal(a.detach().cpu().contiguous().reshape(-1).view(torch.uint8),
                       b.detach().cpu().contiguous().reshape(-1).view(torch.uint8))


def compare(ac_state: dict, encoder_state: dict) -> dict:
    """两份（已去前缀的）状态字典的比较记录。"""
    ac, enc = strip(ac_state), strip(encoder_state)
    names = sorted(set(ac) & set(enc))
    dtype_mismatch, shape_mismatch, equal, max_abs = [], [], 0, 0.
    for name in names:
        a, b = ac[name], enc[name]
        if a.shape != b.shape:
            shape_mismatch.append(name)
            continue
        if a.dtype != b.dtype:
            dtype_mismatch.append(dict(name=name, ac=str(a.dtype), encoder=str(b.dtype)))
        elif _bytes_equal(a, b):
            equal += 1
        if a.numel():
            max_abs = max(max_abs, float((a.detach().cpu().double()-b.detach().cpu().double()).abs().max()))
    unmatched_ac, unmatched_encoder = sorted(set(ac)-set(enc)), sorted(set(enc)-set(ac))
    if unmatched_ac or unmatched_encoder:
        verdict = "missing_keys"
    elif dtype_mismatch or shape_mismatch or equal != len(names):
        verdict = "different"
    else:
        verdict = "same"
    return dict(paired=len(names), bitwise_equal=equal, max_abs_diff=max_abs, unmatched_ac=unmatched_ac,
                unmatched_encoder=unmatched_encoder, dtype_mismatch=dtype_mismatch, shape_mismatch=shape_mismatch,
                verdict=verdict)


def identity_report(ac_checkpoint: dict, encoder_checkpoint: dict) -> dict:
    """两份 torch.load 出来的检查点（顶层是 dict）→ 报告的比较部分。主比较缺键报 KeyError。"""
    if type(ac_checkpoint) is not dict or type(encoder_checkpoint) is not dict:
        raise TypeError("checkpoints must load as dicts")
    for owner, content, key in (("AC", ac_checkpoint, PRIMARY[0]), ("encoder", encoder_checkpoint, PRIMARY[1])):
        if key not in content:
            raise KeyError(f"{owner} checkpoint has no '{key}' entry")
    comparisons = []
    for a in AC_KEYS:
        for b in ENCODER_KEYS:
            if a in ac_checkpoint and b in encoder_checkpoint:
                comparisons.append(dict(ac_key=a, encoder_key=b, primary=(a, b) == PRIMARY,
                                        **compare(ac_checkpoint[a], encoder_checkpoint[b])))
    primary = next(c for c in comparisons if c["primary"])
    return dict(primary=dict(ac_key=PRIMARY[0], encoder_key=PRIMARY[1]), verdict=primary["verdict"], comparisons=comparisons)
```

```python
2. 半群律精确的漂移 Φ_T(z) = z + Tβq，β = 0.01，q = (1, 1, −1, −1)（沿 E 均值 0、和 t 正交）：所有差都为 0。
3. 不满足半群律的漂移 Φ_T(z) = z + T²βq：Φ_Π = z + (Στ_i²)βq，所以 Φ_T − Φ_Π = 2x(Π)βq，
   pd_in(T, Π) = 2x(Π)β/√1.25（正比于 x(Π)），tcd_unequal_in = 2β/√1.25。LN 空间：幅度 A 的 token 上
   LN(A t + S q) = (A t + S q)/√(A² + S² + 1e-5)，记 α = A/√(…)、γ = S/√(…)，则 RMS_LN 的平方是 Δα² + Δγ² 在 token 上的平均，
   JEPA 距离 mean|LN(a) − LN(b)| 是 max(|Δα|, |Δγ|) 在 token 上的平均（目标 −z 的 α = −A/√(A² + 1e-5)、γ = 0）。
模型输出是 float32，线性玩具的比较用 rel=1e-4（c·z 的舍入相对差到 ~3e-5），漂移玩具用 rel=1e-5。

class Toy(torch.nn.Module):
    """kind：semigroup（e^{−aT}z）、linear（(1 − aT)z）、drift（z + Tβq）、quadratic（z + T²βq）、
    fine_drift（16×16 上 z + Tβq，粗网格上原样返回 z，只用来核 scd_ln 和 xpd 的跨网格一侧）；记录每次调用 (N, T)。"""
    def __init__(self, kind):
        super().__init__()
        self.kind, self.calls = kind, []

    def forward(self, raw, controls, duration, grid):
        t = float(duration[0])
        if raw.shape[1] != grid.height*grid.width or float(controls.duration[0]) != t:
            raise AssertionError("toy received inconsistent grid/controls")
        self.calls.append((raw.shape[1], t))
        if self.kind == "semigroup":
            return (raw.double()*math.exp(-A*t)).float()
        if self.kind == "linear":
            return (raw.double()*(1-A*t)).float()
        if self.kind == "fine_drift" and raw.shape[1] != 256:
            return raw.clone()
        shift = BETA*(t*t if self.kind == "quadratic" else t)
        return (raw.double()+shift*Q.double()).float()


def toy_z():
    i = torch.arange(16).repeat_interleave(16)
    j = torch.arange(16).repeat(16)
    amp = torch.where((i+j) % 2 == 0, 1.5, .5)
    sign = torch.tensor([1., -1., 1., -1.])
    return (amp[:, None]*sign[None, :])[None].to(torch.float32)


def toy_window(duration, tid=36, start=0):
    """动作：32 段各 1 个 tick，u_x = 0.01·(k+1)；目标 −z。"""
    metadata = dict(trajectory_id=tid, controls=dict(starts_ticks=list(range(32)), ends_ticks=list(range(1, 33)),
                    values=[[.01*(k+1), 0.] for k in range(32)], units="simulation_position_per_second"))
    controls = cache._window_controls(metadata, start, float(duration), "cpu")
    z = toy_z()
    x = cache.WindowInput(z, controls, torch.tensor([float(duration)], dtype=torch.float64), cache.regular_grid(16, 16),
                          torch.tensor([start*.25], dtype=torch.float64), "input", tid, "test")
    y = cache.WindowTarget(-z, torch.tensor([(start+duration)*.25], dtype=torch.float64), "target")
    return cache.CacheWindow(x, y, dict(actual_manifest_sha256=f"manifest-{tid}", generation=dict(evidence_role="real_frozen_encoder"),
                                        observation_variant="canonical"))

def c(parts):
    return math.prod(1-A*p for p in parts)


def ag(amp, shift):
    n = math.sqrt(amp*amp+shift*shift+EPS)
    return amp/n, shift/n


def drift_ln(s1, s2, amps=(1.5, .5)):
    return math.sqrt(sum((ag(a, s1)[0]-ag(a, s2)[0])**2+(ag(a, s1)[1]-ag(a, s2)[1])**2 for a in amps)/len(amps))


def drift_jepa(s1, s2):
    return sum(max(abs(ag(a, s1)[0]-ag(a, s2)[0]), abs(ag(a, s1)[1]-ag(a, s2)[1])) for a in (1.5, .5))/2


def drift_jepa_target(s1):
    return sum(max(abs(ag(a, s1)[0]+a/math.sqrt(a*a+EPS)), abs(ag(a, s1)[1])) for a in (1.5, .5))/2


def sq(parts):
    return BETA*sum(p*p for p in parts)

class SegmentCount(torch.nn.Module):
    """输出随动作的段数变：z + 0.01·段数。v7 的 direct 用在 T/2 处切开再接上的动作（切点落在段内时多一段），

        return z+.01*torch.as_tensor(controls.n_segments).to(z)[:, None, None]
```

```python
def step(name, command, cwd, log):
    print(f"{name} …", flush=True)
    started = time.perf_counter()
    with open(log, "xb") as handle:
        code = subprocess.run(command, cwd=cwd, env=environment(), stdin=subprocess.DEVNULL, stdout=handle, stderr=subprocess.STDOUT).returncode
    if code:
        tail = "\n".join(Path(log).read_text(encoding="utf-8", errors="replace").splitlines()[-40:])
        raise SystemExit(f"{tail}\nD4 冒烟：失败（{name} 退出码 {code}，见 {log}）")
    print(f"{name} 完成（{time.perf_counter()-started:.0f} 秒）", flush=True)

def enter_new_tree(ac_checkpoint):
    """导入 po_jepa 之前定好环境、路径、线程；真的核一次清单；打 AC 缩小补丁和冒烟补丁（和 v7 树的 smoke_v7_cpu.py --updates 20 相同）。"""
    os.environ.update(SMOKE_ENV)
    os.environ["PO_JEPA_AC_CHECKPOINT"] = str(Path(ac_checkpoint).resolve())
    if Path(sys.path[0] or os.curdir).resolve() != HERE:
        raise RuntimeError("sys.path[0] 应是本脚本所在目录")
    sys.path[0] = str(NEW_TREE/"src")
    torch.set_num_threads(dual.THREADS)
    if torch.get_num_threads() != 1 or any(os.environ.get(k) != v for k, v in dual.WORKER_ENV.items()):
        raise RuntimeError("子进程环境和 WORKER_ENV 不同（请通过父进程运行）")
    from po_jepa.runtime import cache, checks, workflow
    bundle = workflow.verify_bundle()
    from po_jepa import ac_baseline
    ac_baseline.OFFICIAL = ac_baseline.ACSpec(**dual.REDUCED_OFFICIAL)
    original = cache._read_v7_cache
    def as_real(path, m, sha):
        m = copy.deepcopy(m); g = m["generation"]
        g.update(evidence_role="real_frozen_encoder", encoder_checkpoint_sha256=cache.CHECKPOINT_SHA,
                 encoder_load_report=dict(sha256=cache.CHECKPOINT_SHA, encoder_key="target_encoder", strict=True,
                                          missing_keys=[], unexpected_keys=[]))
        return original(path, m, sha)
    cache._read_v7_cache = as_real
    full = checks.load_protocol
    def tiny():
        c = copy.deepcopy(full())
        c["training"]["updates_per_condition"] = UPDATES
        c["loss"].update(lr_decay_updates=UPDATES, lr_warmup_updates=1, consistency_warmup_updates=1)
        c["validation"]["interval_updates"] = max(1, UPDATES//2)
        c["monitoring"].update(early_check_updates=10**9, consistency_interval=2)
        c["calibration"].update(pretrain_updates=2, batches=2)
        return c
    checks.load_protocol = tiny
    workflow.verify_bundle = lambda: "smoke"
    return bundle


def bind_calibrations(v7, addon_output):
    from po_jepa.runtime import checks
    from po_jepa.runtime.addon import calibration
    v7_calibration = Path(v7).resolve()/"smoke/calibration.yaml"
    checks.v7_calibration_path = lambda: v7_calibration
    addon_calibration = Path(addon_output).resolve()/"addon-calibration.yaml"
    calibration.addon_calibration_path = lambda: addon_calibration
    return v7_calibration, addon_calibration


def addon_worker(a):
    started = time.perf_counter()
    bundle = enter_new_tree(a.ac_checkpoint)
    import yaml
    from po_jepa.runtime import cache, checks, v7jobs, workflow
    from po_jepa.runtime.addon import calibration
    v7_calibration, addon_calibration = bind_calibrations(a.v7, a.output)
    v = yaml.safe_load(v7_calibration.read_text(encoding="utf-8"))
    entry = dict(rho=checks.load_protocol()["calibration"]["rho"], time_weight=v["time_weight"], space_weight=v["space_weight"], source="d4 smoke")
    addon_calibration.write_text(yaml.safe_dump(dict(fixed_fourier=entry, transformer_consistency=dict(entry),
                                                     sigma_z_used=checks.load_protocol()["model"]["graph"]["sigma_z"],
                                                     v7_calibration_sha256=cache.file_sha(v7_calibration)), sort_keys=True), encoding="utf-8")
    workflow.require_calibrated_weights(swept=True)
    calibration.require_addon_calibration()
    seconds = {}
    for c in ADDON:
        t0 = time.perf_counter()
        v7jobs.run_job(a.features.resolve(), a.output.resolve()/"jobs"/c, torch.device("cpu"), c)
        seconds[c] = time.perf_counter()-t0
        print(f"{c} {seconds[c]:.0f} s", flush=True)
    cache._write_json(a.output/"worker.json", dict(tree=str(NEW_TREE), verify_bundle_sha256=bundle, seconds=seconds,
                                                   total_seconds=time.perf_counter()-started, threads=torch.get_num_threads()))


def _reseal(folder):
    from po_jepa.runtime import cache
    (folder/"COMPLETE.json").unlink()
    cache._write_json(folder/"COMPLETE.json", dict(report_sha256=cache.file_sha(folder/"report.json")))


def _rewrite(path, change):
    value = json.loads(path.read_text(encoding="utf-8"))
    change(value)
    path.unlink()
    from po_jepa.runtime import cache
    cache._write_json(path, value)


def mutate(job, case):
    """在 job（po_jepa_full 任务的副本）上做一种改坏；改完把报告、选点记录、COMPLETE.json 重新封好，只让目标那一项不符。"""
    train = job/"training"/"po_jepa_full"
    best = json.loads((train/"report.json").read_text(encoding="utf-8"))["best"]
    path = train/best["checkpoint"]
    if case == "checkpoint_bytes":
        path.write_bytes(path.read_bytes()+b"\0")
        return
    payload = torch.load(path, map_location="cpu", weights_only=True)
    if case == "completed_steps":
        payload["completed_steps"] += 1
    elif case == "model_config":
        payload["model_config"]["graph"]["sigma_z"] *= 2
    elif case == "loss_config":
        payload["loss_config"]["time_weight"] *= 2
    elif case == "model_state":
        name = next(iter(payload["model_state"]))
        payload["model_state"]["renamed."+name] = payload["model_state"].pop(name)
    elif case == "data_field":
        payload["provenance"]["feature_manifest_sha256"] = "0"*64
    elif case == "source_files_sha256":
        payload["provenance"]["source_files_sha256"] = {k: "0"*64 for k in payload["provenance"]["source_files_sha256"]}
    path.unlink()
    torch.save(payload, path)
    from po_jepa.runtime import cache
    sha = cache.file_sha(path)
    def fix(record):
        if record.get("step") == best["step"]:
            record["checkpoint_sha256"] = sha
            record["checkpoint_provenance"] = payload["provenance"]
    def fix_training(report):
        fix(report["best"])
        for row in report["validations"]:
            fix(row)
    _rewrite(train/"report.json", fix_training)
    _reseal(train)
    _rewrite(job/"report.json", lambda r: fix(r["best"]))
    _reseal(job)


EXPECTED = dict(checkpoint_bytes="checkpoint SHA mismatch before loading", completed_steps="completed_steps differs",
                model_config="condition/model_config/loss_config", loss_config="condition/model_config/loss_config",
                model_state="model state keys mismatch", data_field="data provenance differs from the current features")


def d4_worker(a):
    started = time.perf_counter()
    bundle = enter_new_tree(a.ac_checkpoint)
    from po_jepa.runtime import cache, comparison
    from po_jepa.runtime.addon import d4, spectral_gap, v7load
    bind_calibrations(a.v7, a.addon)
    features, out = a.features.resolve(), a.output.resolve()
    device = torch.device("cpu")
    jobs = {c: Path(a.v7).resolve()/"smoke/jobs"/c for c in dual.JOB_ORDER}
    jobs["po_jepa_full-evaluate"] = Path(a.v7).resolve()/"smoke/jobs/po_jepa_full-evaluate"
    jobs.update({c: Path(a.addon).resolve()/"jobs"/c for c in ADDON})
    result, problems = dict(jobs={}, mutations={}, perturbation={}), []
    for name, job in jobs.items():
        condition = name.removesuffix("-evaluate")
        t0 = time.perf_counter()
        report = d4.run_d4(features, out/"jobs"/name, device, condition, training_run=job)
        source = json.loads((out/"jobs"/name/"source.json").read_text(encoding="utf-8"))
        eq = report["equivalence"]["metrics"]
        entry = dict(seconds=time.perf_counter()-t0, status=report["status"], counts=report["counts"],
                     equivalence={m: (s["count"], s["bitwise_equal"], s["max_abs_diff"]) for m, s in eq.items()},
                     triangle_violations=report["triangle"]["violations"], training_dir=source["training_dir"])
        result["jobs"][name] = entry
        print(f"d4 {name} {entry['seconds']:.0f} s {entry['equivalence']}", flush=True)
        if report["status"] != "passed" or report["counts"] != dict(windows=20, long_trajectories=4, test_trajectories=4):
            problems.append(f"{name}: status/counts")
        if any(count != bitwise for count, bitwise, _ in entry["equivalence"].values()):
            problems.append(f"{name}: equivalence not bitwise")
        if name == "po_jepa_full-evaluate" and source["training_dir"] != str((jobs["po_jepa_full"]/"training/po_jepa_full").resolve()):
            problems.append("po_jepa_full-evaluate: linked training directory")
    full = json.loads((out/"jobs/po_jepa_full/report.json").read_text(encoding="utf-8"))
    linked = json.loads((out/"jobs/po_jepa_full-evaluate/report.json").read_text(encoding="utf-8"))
    if full["trajectory_macro_means"] != linked["trajectory_macro_means"] or full["long_means"] != linked["long_means"]:
        problems.append("po_jepa_full and po_jepa_full-evaluate differ")
    t0 = time.perf_counter()
    gap = spectral_gap.run_spectral_gap(features, out/"spectral-gap", "cpu")
    result["spectral_gap"] = dict(seconds=time.perf_counter()-t0, windows=len(gap["windows"]), decision=gap["summary"]["decision"],
                                  median_ratio={g: e["median_ratio"] for g, e in gap["summary"]["grids"].items()})
    for case in MUTATIONS:
        copy_dir = out/"mutations"/case
        shutil.copytree(jobs["po_jepa_full"], copy_dir)
        mutate(copy_dir, case)
        model, loss = comparison.build_condition("po_jepa_full", device)
        try:
            record = v7load.load_v7_selected(copy_dir, "po_jepa_full", model, loss_config=loss, features=features, device=device)
            outcome = "loaded" if case == "source_files_sha256" and set(record["source_files_sha256"].values()) == {"0"*64} else "loaded-unexpectedly"
        except ValueError as error:
            outcome = "refused" if case in EXPECTED and EXPECTED[case] in str(error) else f"wrong error: {error}"
        result["mutations"][case] = outcome
        if outcome not in ("refused", "loaded"):
            problems.append(f"mutation {case}: {outcome}")
    for case, delta in (("outside", None), ("last_bit", "nextafter")):
        copy_dir = out/"perturbation"/case
        shutil.copytree(jobs["identity"], copy_dir)
        rows = sorted((copy_dir/"evaluation/identity/rows").glob("*.json"))
        def change(row):
            value = row["values"]["future_jepa_distance"]
            import math
            row["values"]["future_jepa_distance"] = math.nextafter(value, math.inf) if delta else value+2e-6*max(1., abs(value))
        _rewrite(rows[0], change)
        try:
            report = d4.run_d4(features, out/"perturbation-d4"/case, device, "identity", training_run=copy_dir)
            outcome = (report["status"], report["equivalence"]["metrics"]["future_jepa_distance"]["bitwise_equal"])
        except ValueError as error:
            outcome = ("failed", str(error))
        result["perturbation"][case] = outcome
    if result["perturbation"]["outside"][0] != "failed" or "equivalence outside tolerance" not in result["perturbation"]["outside"][1]:
        problems.append("perturbation outside tolerance was not refused")
    if result["perturbation"]["last_bit"] != ("passed", 119):
        problems.append(f"last-bit perturbation: {result['perturbation']['last_bit']}")
    windows = sum(sum(c for c, _, _ in j["equivalence"].values()) for j in result["jobs"].values())
    bitwise = sum(sum(b for _, b, _ in j["equivalence"].values()) for j in result["jobs"].values())
    passed = not problems
    line = (f"D4 冒烟：{'通过' if passed else '失败'}（{len(result['jobs'])} 个 D4 任务，等价核对逐位相同 {bitwise}/{windows}，"
            f"三角不等式违反 {sum(j['triangle_violations'] for j in result['jobs'].values())}，"
            f"v7load 改坏 {sum(v in ('refused', 'loaded') for v in result['mutations'].values())}/{len(MUTATIONS)}"
            f"{'' if passed else '；' + '；'.join(problems)}）")
    cache._write_json(out/"d4-smoke.json", dict(result, problems=problems, passed=passed, summary_line=line, verify_bundle_sha256=bundle,
                                                seconds=time.perf_counter()-started, threads=torch.get_num_threads()))
    print(line, flush=True)


def main(argv=None):
    p = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    p.add_argument("--workdir", type=Path)
```

## 4. 接口和数据格式

### 4.1 `po_jepa.runtime.addon.v7load`

- `load_v7_selected(job_dir, condition, model, *, loss_config, features, device) -> dict`：`job_dir` 是任务目录（`v7jobs._job_dir` 的三种写法都收）；`model`、`loss_config` 由调用者用 `comparison.build_condition(condition, device)` 现建；读入后 `model.eval()`。返回 `job_dir`、`job`、`report_sha256`、`training_dir`、`best`（`step`、`mean`、`checkpoint`、`checkpoint_sha256`）、`checkpoint`（配置快照）、`data_fields`、`source_files_sha256`；identity 的后 5 项为 None 或不出现。任何一项不符报 `ValueError`。
- `D4_CONDITIONS`：11 个条件；`DATA_FIELDS`：8 个字段；`training_dir(job_dir, job, condition)`、`job_record(job_dir, condition)`（S18b 的汇总也用 `training_dir` 找续训任务的训练目录）。

### 4.2 `po_jepa.runtime.addon.d4`

- 常量：`TCD_TIMES`、`SCD_GRIDS`、`PARTITIONS`、`CROSS`、`UNEQUAL`、`HELDOUT`、`LONG_TIMES`、`LONG_BLOCK`、`EQUIVALENCE_METRICS`、`EQUIVALENCE_TOLERANCE`、`TRIANGLE_TOLERANCE`。
- 键名：`value_names()`（54 个，每个窗口）、`long_value_names()`（12 个，每条轨迹）、`equivalence_names()`（24 个），`partition_label(parts)`、`partition_x(T, parts)`。键名格式：`tcd_ln:T=4`、`scd_ln:h=8:T=4`、`pd_in:T=8:3+5`、`pd_ln:T=4:8x0.5`、`xpd_in:T=8:n=4`、`tcd_unequal_ln:d=8:6+2`、`heldout_rollout:T=12`、`long_pd_in:T=24`、`future_jepa_distance:T=3`、`scd_normalized:h=12:T=1`。
- `window_values(model, windows, config) -> (values, equivalence, triangle)`、`long_values(model, windows, config) -> values`、`run_d4(features, output, device, condition, *, training_run) -> report`。
