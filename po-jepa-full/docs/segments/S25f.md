## 1. 目标与范围

v8 规划 §1.6 的四个新任务里，长时程滚动已在 S25c 做完；本段做另外三个：

1. **物理状态读出、有效预测时长（VPT）**：在真实画面的冻结特征上拟合线性探针（特征 → 真值状态），用它读模型预测的特征，报物理单位下的滚动误差曲线和 VPT。用 S25c 的 8 步滚动（同一个预测）。
2. **反事实预测**：同一起点、同一噪声，换成 donor 的动作；比较探针读出的预测状态变化和重新仿真的真值变化。
3. **模态频率对照（探索性）**：PO-JEPA 学到的阻尼旋转块（γ、ω）和线性场景（advection_diffusion、spring_chain、wave）的解析模态对照。

12 个场景都能做 1、2（二阶场景照 S25a 要显式 `--scenes`，dup 编码，只读位置）；3 只做三个线性场景、只做 PO-JEPA 条件。只评测，不训练、不用编码器。

不做：S25e 空间采样（另一个线程）、S25b pair 编码；时间采样和空间采样测试集上的读出；汇总表（summarize_v7）的读出一节（见 §5）。

## 3. 约定（Claude 定，Jerry 可以改）

- **读出目标 = 动作探针 *_px 列的量**：‖target(a) − target(b)‖ = `probe_actions.motion(a, b)`（测试对 11 个场景的真实状态和 gray_scott、push 的随机状态核）。所以读出误差和 `action_swap_px` 同一单位：小球、推杆方块、二阶场景是像素，三个场是池化场的 L2。二阶场景只读位置（dup 编码看不到速度）。
- **探针在主实验缓存的验证段上拟合**（2000 条时 200 条 × 33 帧 = 6600 个样本），不碰测试段，也不碰模型训练用的训练段；每个数据集一个，所有条件、种子共用。长时程读出的 tick 32 以后不在探针的拟合范围里，所以同时报探针在真实特征上的误差（floor）和 floor 的 VPT：floor 本身撑不住的地方，模型的 VPT 不能怪模型。
- **探针输入先逐 token 做无仿射 LN**（eps 1e-5，和 JEPA 距离同一个）：模型只被 LN 后的距离约束，原始预测的逐 token 平移和缩放不受约束，探针不应读这两个方向。读出 kind 默认 full（360448 维，对偶形式，存原始形式 W，float32 约 360448 × 输出维）；mean、pool4 可选。
- **λ**：λ = trace(K̃)/n · 10^e，e ∈ −7…2 步长 0.5（S22 的网格），所有输出维共用一个，按轨迹 5 折（编号 mod 5）的合并 R² 选，再在全部验证样本上重拟合。λ 落在网格边上时探针记录里 `lambda_at_grid_edge = true`。
- **VPT**：nmse(t) = ‖R(ẑ_t) − y_t‖²/V，V = 验证段目标的总方差；VPT@ε = 最长的 t 使 t 以前所有曲线点 nmse ≤ ε，ε = 0.05、0.1、0.25；分辨率 8 个 tick（S25c 的曲线点），到 128。三个阈值是 Claude 定的。
- **反事实窗口**：主实验测试窗口（每条测试轨迹的登记起点 × 时长 1、2、4、8，与动作探针相同），donor = delta_act 的 donor；预测都用一次完整 forward Φ(z, u, T)（两条动作对称；不经过 v7 point_metrics 的“T/2 切开再接上”）。真值终点由 `probe_actions.counterfactual_end` 重新仿真（同一真实起点状态、同一份过程噪声；S25a fix1 起只换窗口内的下达动作，窗口前仍是这条轨迹自己的，和 delta_act 一致）。汇总的 explained、gain、cos 只用动作和 donor 不同的窗口；identity 的 explained = gain = 0（预测变化为 0）。
- **真值一次算好存 JSON**（truth 子命令）：反事实要重新仿真（gray_scott 每条约 5 秒），不应在每个条件、种子上重复。truth 核长时程缓存每个曲线点、主实验缓存每个反事实终点的画面哈希与 frames() 重渲染的相同；rollout、counterfactual 核 truth 记的 manifest SHA 和缓存的 encode report SHA。
- **模态频率**：只比分布不配对（模态是逐样本的图谱模态）；能量权重来自起点系数 C0；真值只列 ≤ 4π rad/s（4 fps 的奈奎斯特）的；wave、advection_diffusion 的波数限 |m_x|,|m_y| ≤ 8（16×16 token 网格）。对照量见 modal_spectrum.py 文件头。另报同结构未训练模型（torch 种子 = 任务种子）的同一组量：初始化 ω ≈ 0、γ = 0.4 s⁻¹，advection_diffusion 的 non_oscillatory 在初始化时就接近 1，要和它比。
- **任务表**：R3 跑 3 个种子 × 6 个条件（读出和反事实是主表的两列）；R4 只排 `po_jepa*` 条件。
